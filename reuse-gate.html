The model

Turns your label into English search terms. It never chooses a concept and never sees a version.

The code

Reads the registry and classifies. Evidence — code set, name, id — is reported separately. There is no single confidence number.

The expert

Decides what to reuse and what to create. Nothing proceeds without that decision.

Storage

What the gate matches against. Standard concepts come from the SDMX Global Registry. The second store is observed usage — dimensions and code values read out of an institution's published data. It shows what is in use; it does not establish ownership, maintenance, or which version is official.
